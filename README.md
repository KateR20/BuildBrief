# BuildBrief

## Website Planning Made Simple

BuildBrief is a web application designed to guide individuals and small business owners through the early stages of planning a website.

Many people know they need a website but are unsure where to begin or what their website actually needs. BuildBrief will use a simple step-by-step questionnaire to help users identify their website goals, required pages and features, design preferences, and the materials they already have.

Once the questionnaire is complete, BuildBrief will organize the user's answers into a clear website project brief. This will help users better understand and communicate their website needs while also providing developers with organized information about what their client is looking for.

## Planned Features

- Create a new website project
- Enter basic business and project information
- Identify the main goals and purpose of the website
- Select desired website pages such as Home, About, Services, Gallery and Contact
- Select required features such as contact forms, testimonials, booking options and social media links
- Choose design and style preferences
- Identify existing assets such as a logo, domain name, photographs and written content
- Complete a guided step-by-step website planning questionnaire
- Generate an organized website project brief
- Save project information so it can be viewed or updated later
- Display a summary of items the user already has and items they may still need to prepare
